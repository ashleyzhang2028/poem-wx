# 跬步 · 古诗词背诵微信小程序

[poem](https://cnb.cool/npu-gpu-cpu/poem) 网页版的微信小程序移植。
覆盖小学一年级到高中三年级统编版古诗文 251 首，另设十七部课外集子
（古文观止 / 乐府 / 唐诗 / 词 / 曲 / 昭明文选 / 成语故事 / 文学名著 / 历代名家 / 历代帝王……），
共 5575 条篇目。

**打开即用，不登录也不缺功能；进度只存本机，断网也能背。**

## 快速开始

```bash
# 1. 从 poem 仓库取语料并编译（数据不入库，必须先跑这一步）
git clone --depth 1 https://cnb.cool/npu-gpu-cpu/poem.git /tmp/poem
POEM_WEB_DIR=/tmp/poem node scripts/build-data.js

# 2. 离线自检
node scripts/check.js

# 3. 用微信开发者工具打开 miniprogram/ 目录
```

`appid` 目前是 `touristappid`（游客模式），正式上传前换成自己的。

## 功能

- **每日背诵**：按选择的年级学期与范围排出今天要背的几首，分「复习」与「新学」
- **四套复习算法**：艾宾浩斯遗忘曲线 / 莱特纳盒 / SM-2 / FSRS，设置页可切，**换算法不清进度**
- **背诵范围 6 选 1**：本册及之前 / 小学随机 / 初中随机 / 小初随机 / 高中随机 / 全部随机
- **课外阅读**：十七部集子，按「课内 / 诗文典籍 / 人物 / 文史常识」四张卡分组进入
- **正文全文检索**：搜诗句本身，不只是篇名 ——「明月几时有」「晚来天欲雪」都能搜到
- **注音渲染**：不注音 / 生字 / 全文三档，多音字按词组消歧（「白发」读 fà 不读 fā）
- **朗读**：接 TTS 服务，整篇连读，语速可调
- **背诵进度**：已学 / 已掌握 / 今日到期，未来七天排期，记忆阶段分布
- **古诗词大会**：飞花令（查一查 / 闯关两种玩法）、题库（六种题型）、模拟考试（限时 20 分钟）
- **层级与权限**：与网页版同一张 free / pro / max 能力表，管理页可看可调
- **阅读设置**：对齐方式、字号、注音偏好
- **导出备份**：整份数据复制成 JSON，换手机时导回去
- **云端同步**：登录后进度跨设备，离线照常记，联上自动补

## 界面

配色取自宋代传统色，与网页版**逐值相同**（见 `miniprogram/styles/tokens.wxss`）：

| 变量 | 传统色 | 色值 | 用在哪 |
|---|---|---|---|
| `--green` | 雨过天青 | `#2f6055` | 主色 |
| `--bg` | 素绢 | `#f6f1e3` | 页面底色 |
| `--amber` | 琥珀 | `#a55c19` | 复习标签、模糊按钮 |
| `--red` | 朱砂 | `#a83b32` | 忘记按钮 |
| `--gold` | 缃色 | `#f0cd7c` | 今日进度环 |
| `--blue` | 天水碧 | `#3d6379` | 大会页 |
| `--ink` | 墨 | `#241d18` | 正文 |

诗词用宋体、界面用黑体。**外壳不照搬网页版**：顶栏与底栏换成原生导航栏与原生 tabBar ——
这是小程序的推荐呈现方式，也免掉一整套状态栏与胶囊避让的计算。

## 数据放在哪

正文**不进包**。实测全部正文 24.3 MB（gzip 后 4.9 MB），而主包上限 2 MB、总包 20 MB，
一部《昭明文选》就超了。所以分三层：

- **包内**：各集子索引（篇名/作者/朝代/出处，不含正文）1.0 MB + 读音表 21 KB；主包合计 **1.21 MB**
- **云端**：正文切成 120 个约 200 KB 的分片（23 MB）+ 全文倒排 44 列（8.8 MB），
  放腾讯云 COS + CDN 按需取
- **本机**：背诵进度、设置、已读标记

详细推演见 [`docs/architecture.md`](docs/architecture.md)。

## 层级与权限

能力表与网页版 `js/entitlement.js` **逐条对齐**（自检里有一条专门比这张表，漂了就报错）：

| 门槛 | 能力 |
|---|---|
| **Free** | 每日背诵、课外阅读、注音辅助、艾宾浩斯（都不要求登录） |
| **Free + 登录** | 语音朗读、莱特纳盒、进度导出 |
| **Pro 起** | SM-2、题库、自选清单（10→100）、子用户（1→3）、PDF 打印、课内导出 |
| **Max 起** | FSRS、飞花令、古诗词大会、模拟考试、正式考试 |

**本机档位默认 Max。** 数据只存在这台手机上，不登录不该被卡功能 —— 这是网页版立的规矩。
档位真正有意义的地方在云端（跨设备同步、子用户这些要配额的），那里由服务端按 uid 校验。

「我的 → 管理层级」里能看当前档位、逐条能力开关、改本机档位验权限分支；
配了后端且是管理员，还能读名录、改档位与角色。

## 朗读：TTS 收不收钱

**能免费做，但要企业主体。** 三条路：

| 方案 | 费用 | 门槛 |
|---|---|---|
| 微信同声传译插件 | 免费 | 要在公众平台申请插件权限，**个人主体走不通** |
| 自建 TTS（腾讯云 / 讯飞 / 火山） | 收费 | 自家后端签名，要配 request 域名 |
| 没有可用 provider | — | 明确告知「朗读不可用」，不静默失败 |

代码按多 provider 写好了，默认走同声传译；`appid` 从 `touristappid` 换成正式号
并申请到插件后，改 `app.json` 加一段 `plugins` 声明即可，业务代码不用动。

## 还没做的

记账，免得看成「已补齐」：

- **注音勘误**：网页版有用户提交读音修正的审核队列，小程序端没搬（依赖后端）
- **子用户 / 家庭**：能力表里留了 `profile.family`，界面没做
- **PDF / 打印**：小程序端做不了，跳网页版
- **正式考试 / 文学常识考试**：依赖后端组卷判分，入口没列出来 ——
  列一个点不动的入口比没有更糟
- **云端同步**：契约与离线队列都写好并测过，但后端 `/api/sync/*` 还没部署，
  现在实际走的是本机
