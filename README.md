# 跬步 · 古诗词背诵微信小程序

[poem](https://cnb.cool/npu-gpu-cpu/poem) 网页版的微信小程序移植。
覆盖小学一年级到高中三年级统编版古诗文 251 首，另设十七部课外集子
（古文观止 / 乐府 / 唐诗 / 词 / 曲 / 昭明文选 / 成语故事 / 文学名著 / 历代名家 / 历代帝王……），
共 5575 条篇目。

**打开即用，不登录也不缺功能；进度只存本机，断网也能背。**

## 快速开始

```bash
# 1. 从 poem 仓库取语料并编译（数据不入库，必须先跑这一步）
git clone --depth 1 https://cnb.cool/npu-gpu-cpu/poem.git /tmp/poem
POEM_WEB_DIR=/tmp/poem node scripts/build-data.js

# 2. 离线自检
node scripts/check.js

# 3. 用微信开发者工具打开 miniprogram/ 目录
```

`appid` 目前是 `touristappid`（游客模式），正式上传前换成自己的。

## 功能

- **每日背诵**：按选择的年级学期与范围排出今天要背的几首，分「复习」与「新学」
- **四套复习算法**：艾宾浩斯遗忘曲线 / 莱特纳盒 / SM-2 / FSRS，设置页可切，**换算法不清进度**
- **背诵范围 6 选 1**：本册及之前 / 小学随机 / 初中随机 / 小初随机 / 高中随机 / 全部随机
- **课外阅读**：十七部集子，按「课内 / 诗文典籍 / 人物 / 文史常识」四张卡分组进入
- **全站搜索**：搜篇名 / 作者 / 朝代 / 出处，可切「全站」或「课内」
- **背诵进度**：已学 / 已掌握 / 今日到期，未来七天排期，记忆阶段分布
- **古诗词大会**：飞花令（课内 251 首里按字找句）、模拟考试（限时 20 分钟，三种题型）
- **阅读设置**：对齐方式、字号、注音偏好
- **导出备份**：整份数据复制成 JSON，换手机时导回去

## 界面

配色取自宋代传统色，与网页版**逐值相同**（见 `miniprogram/styles/tokens.wxss`）：

| 变量 | 传统色 | 色值 | 用在哪 |
|---|---|---|---|
| `--green` | 雨过天青 | `#2f6055` | 主色 |
| `--bg` | 素绢 | `#f6f1e3` | 页面底色 |
| `--amber` | 琥珀 | `#a55c19` | 复习标签、模糊按钮 |
| `--red` | 朱砂 | `#a83b32` | 忘记按钮 |
| `--gold` | 缃色 | `#f0cd7c` | 今日进度环 |
| `--blue` | 天水碧 | `#3d6379` | 大会页 |
| `--ink` | 墨 | `#241d18` | 正文 |

诗词用宋体、界面用黑体。**外壳不照搬网页版**：顶栏与底栏换成原生导航栏与原生 tabBar ——
这是小程序的推荐呈现方式，也免掉一整套状态栏与胶囊避让的计算。

## 数据放在哪

正文**不全进包，但课内那 251 首进包**。实测全部正文 24.3 MB（gzip 后 4.9 MB），
而主包上限 2 MB、总包 20 MB，一部《昭明文选》就超了；课内 251 首只有 223 KB。
所以分三层：

- **包内**：各集子索引（1.0 MB）+ **课内 251 首的正文与译文**（223 KB）；主包合计 **1.30 MB**
- **云端**：其余 5324 条正文切成 119 个约 200 KB 的分片（合计 23 MB），放腾讯云 COS + CDN 按需取
- **本机**：背诵进度、设置、已读标记

课内正文进包是刻意的：首页「每日背诵」与详情页都靠它，223 KB 换掉一次云端往返，
省下的是每天真正被打开的那两个页面的等待。边界由自检验着 —— 课内进包、课外走分片，
同一份正文不许两边各存一份。

详细推演见 [`docs/architecture.md`](docs/architecture.md)。
